# 新手装备清单（广财羽动未来俱乐部）

> 按「先解决受伤风险，再解决手感」的顺序买。
> 预算有限时，从第一优先开始，逐级往上加。

## 第一优先 · 必买

- [ ] **羽毛球鞋**（1 双，300–600 元档即可）
  - 要求：防滑橡胶底、侧向支撑好、包裹贴合
  - 不要：穿跑鞋、板鞋、帆布鞋上场（最容易崴脚）
  - 建议：只在场馆里穿，别穿去上课，鞋底会磨掉

- [ ] **球拍**（1 支，200–400 元档）
  - 重量：4U（约 80–84g）或 5U（约 75–79g）
  - 中杆：中等偏软，好借力、容错高
  - 磅数：先拉 22–24 磅，别一上手就 28 磅
  - 不要：买来就换线、换手胶、上高磅

## 第二优先 · 建议买

- [ ] **手胶**（一包 3–5 条）
  - 吸汗防滑，成本低，脏了勤换
  - 比买贵拍更能改善握持手感

- [ ] **羽毛球**（一筒）
  - 训练用：耐打的鸭毛球或复合球
  - 比赛用：鹅毛球
  - 一筒球打多久取决于毛片散不散，新手对拉损耗更快

## 第三优先 · 可等等

- [ ] 护腕 / 护膝 / 踝套 —— 有旧伤再买，没伤不必提前戴
- [ ] 高端球拍（800 元以上）—— 动作定型前帮助很小
- [ ] 专业球包 —— 先用普通双肩包完全够
- [ ] 拍线备用 —— 断了再换，不用囤

## 简单判断标准

| 情况 | 建议 |
| --- | --- |
| 一周打 1 次 | 鞋 + 4U 拍 + 手胶，够了 |
| 一周打 2–3 次 | 加一筒训练球，考虑第二支拍备用 |
| 想打内部赛 | 换鹅毛比赛球，拍线可提到 24–26 磅 |
| 有旧伤 | 先看医生，再考虑护具，别硬撑 |

## 一句话总结

**鞋 > 拍 > 手胶 > 球**。把钱先花在脚上，别花在参数上。
