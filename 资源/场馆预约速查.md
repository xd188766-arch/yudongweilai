# 场馆预约速查卡

> 广东财经大学体育馆 · 羽毛球场地
> 俱乐部内部整理，供成员日常约场使用。规则以学校预约系统为准。

## 一、记住三件事

1. **每天 12:00 放场**
2. **放的是两天后的场**（今天 +2）
3. **每人每天 2 场，每周 4 场**

## 二、额度与限制

| 项目 | 规则 |
| --- | --- |
| 放场时间 | 每天 12:00 |
| 可约日期 | 今天 +2 天 |
| 每人每天 | 最多 2 场 |
| 每人每周 | 最多 4 场 |
| 同一时段 | 只能约 1 块场地 |
| 教学 / 工会占用 | 系统自动跳过，不可选 |

## 三、四步流程

1. 提前 5 分钟打开预约系统，确认仍处于登录状态
2. 12:00 后选择「今天 +2」那一格（12:00 前是灰的）
3. 选时段与场地：已被预订 / 教学占用的场地不可选
4. 提交后回到「我的预约」确认订单，截图保存时段与场地号

## 四、常见失败原因对照

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示「暂未开放」 | 还没到 12:00，或日期格子未激活 | 等 12:00，刷新后重选 |
| 跳回登录页 | 登录态过期 | 重新登录，再回来抢 |
| 场地全是灰的 | 该日已被约满 / 教学占用 | 换时段或换日期 |
| 提示已达上限 | 当日 2 场或当周 4 场用满 | 换一天，或与成员互助 |
| 提交后无订单 | 同一时段已约过 | 检查「我的预约」 |

## 五、俱乐部约定

- 抢到不打，提前在群里说，别让场地空着
- 不占坑：额度不要「先占着再说」
- 取消是否返还额度**尚未确认**，谨慎操作
- 互助排班：抢不到的成员由抢到的成员带一场

## 六、提醒

- 提前到场 10 分钟，热身再上场
- 自带球拍与球鞋，俱乐部只提供少量公用球
- 结束后带走垃圾，把场地恢复原样
